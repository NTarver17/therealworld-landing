# The Real World 2.0 - High-Converting Landing Page & Affiliate Portal

A modern, high-performance, dark-mode landing page mirroring **The Real World** portal with interactive campus filtering, custom ROI calculator, live interface sneak peek simulator, social proof notification engine, and affiliate checkout routing.

## 🚀 Features

- **High-Converting Hero Section:** Animated stats, verified ratings (4.98/5), and live TRW 2.0 terminal mockup.
- **Urgency & Price Lock System:** Real-time synchronized 24-hour countdown timers and "98% Sold Out" cohort progress meter.
- **Interactive Potential Income & Campus Calculator:** Dynamic roadmap generator based on daily time availability, budget ($0 to $1,000+), and 90-day targets.
- **Inside The Real World 2.0 Simulator:** Tabbed UI preview of real-time signals, multimillionaire Q&A, and student earnings feed.
- **10+ Wealth Campuses:** Interactive category filtering for AI Automation, Client Acquisition, Copywriting, E-Commerce, Crypto Altcoins, Trading, and more.
- **Exit-Intent Recovery Modal:** Recovers abandoning visitors with automated price-lock countdown.
- **Universal Affiliate Routing:** Dynamic query parameter preservation for affiliate tracking.
- **Monetization & AdSense Ready:** Pre-configured with Google AdSense meta tags, auto ads scripts, and `ads.txt`.

## 🛠️ Tech Stack

- HTML5 (Semantic & SEO-optimized)
- Vanilla CSS3 (Custom design system, glassmorphism, responsive breakpoints)
- Modern JavaScript (ES6+ modular interactions)
